# BEX

Chrome 拡張機能が動く Android ブラウザ。Chromium を改造し、PC 版の拡張機能を
スマートフォンで使えるようにしたものです。

|---|---|
| <img src="docs/images/extensions-page.png" width="280"> | <img src="docs/images/extensions-menu.png" width="280"> |

## できること

- **任意の Manifest V3 拡張機能が動く。** 提供元が用意した限定リストではありません
- **Chrome ウェブストアから検索・インストール・削除ができる**
- **自作の拡張機能をフォルダから読み込める。** PC につながなくても、スマホの上で
  そのままテストできます
- **拡張機能をホーム画面に置ける。** BEX のアイコンを長押しすると拡張機能が並び、
  ドラッグして置けばアプリのように直接起動できます
- 拡張機能の UI をモバイルで扱えるようにしてあります
  - ツールバーのアイコンから拡張機能を呼び出す
  - ポップアップは画面下から出るシートで表示
  - サイドパネルに対応
  - アドレスバーに拡張機能のキーワードを入れて、その拡張機能に検索を渡す

動作確認済み: uBlock Origin Lite（広告ブロック）、自作拡張数種。

## 使う

[リリース](../../releases)から APK をダウンロードし、「提供元不明のアプリ」を
許可してインストールしてください。パッケージ名は `com.rou39.bex` で、
Chrome / Chromium とは別のアプリとして共存します。

新しい版が出ると、起動時に気づいて三点メニューに「更新」が出ます。
設定 → BEX について → 「更新を確認」からも調べられます。

> [!WARNING]
> **実験的なビルドです。常用は推奨しません。**
> セキュリティ更新は保証されません（Chromium は約4週間ごとに脆弱性修正を出しますが、
> このビルドが同じ速度で追随することはありません）。パスワードや決済情報など、
> 機微な情報の入力には使わないでください。

> [!NOTE]
> **BEX で再生している音は、他のアプリから録音できます。**
> 画面録画に音を入れられるようにするため、`allowAudioPlaybackCapture` を有効に
> しています（Chrome は無効）。画面録画アプリに限らず、音声キャプチャを行う
> アプリ全般が対象です。
