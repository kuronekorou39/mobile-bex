# 実機スモークテスト手順書

リビルド後に実機で確認する項目の一覧。全項目で「クラッシュしないこと」を暗黙の合格条件とする。

自動テスト (Robolectric) は BottomSheet ポップアップ周りに 25 件あり、
`autoninja -C out/MobileBex chrome_junit_tests` でビルドして
`out/MobileBex/bin/run_chrome_junit_tests -f "*ExtensionBottomSheet*"` で実行できる。
本書はそれでは確認できない実機の挙動を対象とする。

- 対象端末: Pixel 9a (Android 16) / SHV48 (Android 10)
- テスト拡張機能: デスクトップの `bex-test-*.zip`（`zip-extensions.ps1` で再生成）
- **`test-extensions/devtools` は読み込まない**（起動ハング既知問題。復旧は
  `scripts/strip-devtools-extension.py`）

## 2.5 シークレットモード（Patch 36）

「シークレット モードでの実行を許可する」は、拡張機能が対応を宣言している場合のみ
詳細ページに出る。出ない拡張機能ではこの節は確認できない。

| # | 手順 | 期待結果 |
|---|------|---------|
| 2.5-1 | 許可を付けた拡張機能を、シークレットタブで開く | **落ちない**（旧: tabs_api.cc の CHECK でプロセス終了） |
| 2.5-2 | ウィンドウを要する操作（例: Parallel Stream の「マルチビューを開く」） | 成功する（旧: `No current window`） |
| 2.5-3 | 上で開いたタブの所属 | **シークレット側**のタブグループに入る（通常側に漏れないこと） |
| 2.5-4 | シークレットタブを全部閉じてから、通常タブで拡張機能を操作 | 落ちない・エラーにならない（プロファイル破棄後の隙間の確認） |

## 10. ホーム画面ショートカット（Patch 35）

| # | 手順 | 期待結果 |
|---|------|---------|
| 10-1 | ホーム画面の BEX アイコンを長押し | インストール済みの拡張機能が、各自のアイコンとタイトルで並ぶ |
| 10-2 | 並んだ拡張機能をホーム画面にドラッグ | 単体のアイコンとして置ける |
| 10-3 | 置いたアイコンをタップ | BEX が起動し、その拡張機能が実行される（ポップアップがあれば開く） |
| 10-4 | BEX を開いたままショートカットをタップ | 同上（起動済みの場合は onNewIntent 経由。別経路なので必ず両方見る） |
| 10-5 | 起動後に画面を回転 | 拡張機能が**再実行されない**（intent の extra を消す処理の確認） |
| 10-6 | 「シークレット タブ」の項目 | 長押しの一覧に**残っている**（拡張機能の登録に巻き込まれて消えないこと） |
| 10-7 | 拡張機能を追加・削除して再起動 | 長押しの一覧が追随する |
| 10-8 | 削除済み拡張機能のアイコンをホーム画面に残してタップ | 「この拡張機能は利用できません」。**落ちないこと**（Patch 35 の null チェック） |
| 10-9 | 拡張機能ゼロの状態で長押し | 拡張機能は並ばない。クラッシュしない |

ショートカットの登録状態は `adb shell dumpsys shortcut` で確認できる。
`bitmap size` が数百バイトならアイコンが透明（読み込み待ちのまま publish された）。
