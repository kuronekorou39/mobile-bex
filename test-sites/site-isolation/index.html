親ページ（攻撃側サイトの役）

このページのサイト:

下の枠は別サイト を iframe で埋め込んでいる。

見るところ

  1. 別タブで chrome://process-internals を開く
  2. General タブの Site Isolation mode を確認する
  3. Frame Trees タブで、このページと iframe の Process ID を比べる
    • 同じ → 2つのサイトが1つのレンダラープロセスに同居している
    • 違う → iframe は別プロセスに分離されている
  4. 被害側サイトのログインページでパスワード欄に何か入力し、 このページを新しいタブで開き直して 3 をもう一度確認する （パスワードを入力したサイトは、以後分離対象になる）
